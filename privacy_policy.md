# Privacy Policy

Last updated: 2026-05-09

## Overview

GMail: search in inbox is a browser extension that adds a button and keyboard shortcut to Gmail's search field. When triggered, it appends `in:inbox` to the current Gmail search query and runs the search.

## Data handling

This extension does not collect, store, transmit, sell, or share personal data.

The extension runs only on `https://mail.google.com/*` and only accesses the Gmail page content needed to:

- add the search-in-inbox button to the Gmail interface
- detect the current search query in the Gmail search field
- append `in:inbox` when the user clicks the button or uses the keyboard shortcut
- trigger the Gmail search action

All processing happens locally in the user's browser. No data is sent to the developer or to any third party by this extension.

## Permissions

The extension is limited to `https://mail.google.com/*` because it needs to modify Gmail's search interface on that site.

## Remote code and external services

This extension does not use remote code, external analytics, or external services.

## Changes

If this privacy policy changes, the updated version will be published in this repository.
